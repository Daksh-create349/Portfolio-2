# Daksh Srivastava — Personal Portfolio

An ultra-refined, award-winning-style personal portfolio for **Daksh Srivastava** (Full-stack Developer & CS Undergraduate, CGPA: 9.57 at ITM Skills University), inspired by the craft, fluid micro-interactions, dark/light theming, and aesthetics of `poulo.site`.

## 🚀 Highlights & Features

- **Floating Glassmorphic Header**: Blur dock with smooth indicator pills, Dark/Light mode switcher with rotate animation, and the signature "Get in touch" sliding dot matrix button.
- **Desktop Side Preview Rail**: Fixed vertical navigation rail (`#home`, `#work`, `#experiments`, `#about`, `#stack`) with live section highlighting and smooth scroll.
- **Interactive Cursor-Tracking Avatar**: Custom SVG developer portrait with real-time cursor tracking (`--look`), smooth head and eye parallax, and natural periodic blinking (`--blink`).
- **Hero Section**:
  - Dynamic rotating/morphing title (`Full-Stack Developer`, `AI Systems Engineer`, `DevSecOps Specialist`, `Geospatial AI Builder`).
  - Liquid wave "About Daksh" button with hold-to-fill interaction.
  - Metallic iridescent shimmer "See my work" button.
  - Interactive right-side accordion.
- **Atmospheric Background Canvas**: Stepped glassmorphism backdrop-filter blur masks, real-time particle connection field, and drifting cloud sprites.
- **Impactful Initiatives & Organizations**: Dynamic carousel showcasing Google Student Ambassador, Sahajta AI, Hacktoberfest x MLH Hack Day Winner, Microsoft Edge Add-ons, 100x Applied AI, and ITM Skills University.
- **Selected Work Bento Wall**: Real-time 42-bar audio spectrum visualizer (Web Audio API simulation), Sentinel-1 SAR radar sweep canvas, Git DAG forensics tree, and Gemini Live audio stream.
- **Flagship Project Showcases (4 Deep Case Studies)**:
  1. **Sonaura 2.0 — Browser Audio DSP Extension** (Web Audio API, 5.1 HRTF, 10-Band EQ, Edge Store Launch)
  2. **AQUILA — Climate Intelligence Engine** (FastAPI, Google Earth Engine, Sentinel-1 SAR, Three.js 3D Globe, XGBoost)
  3. **GitHub Guardian — DevSecOps Security Auditing Platform** (Git DAG commit traversal, non-linear SAST, AI Reviewer)
  4. **HyperMind — Adaptive AI Learning Companion** (Gemini 2.5 Flash/Pro, Gemini Live real-time audio, Generative UI with Recharts & ReactFlow)
  - Features simulated prompt loaders, live tags, category filter chips (`Show all`, `Audio DSP`, `Geospatial`, `DevSecOps`, `AI & Agentics`), and 4-pillar architectural cards with 3D tilt and icon rotation on hover.
- **AI Experiments & Interactive Labs**:
  - Interactive 3D Binaural DSP Lab with Haas delay slider (1–35ms).
  - DevSecOps Git DAG Inspector with clickable commit nodes and live SAST leak alerts.
  - Geospatial Flood Basin Simulator with topographic elevation slider.
- **"Ask Me Anything" Interactive AI Assistant**: In-browser knowledge agent trained on Daksh's complete technical repertoire, academic stats (CGPA 9.57), coursework, and achievements, with follow-up suggestion chips.
- **Academic & Professional Journey**: Timeline table with roles, organizations, locations, and dates.
- **My Stack**: Interactive 18+ technology grid with monochrome-to-color hover states.
- **Contact Modal**: Direct email copy with confetti explosion, phone, LinkedIn, and GitHub links.
- **Footer**: Live Mumbai (IST) digital clock updated every second, social links, and back-to-top button.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router, React 19)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, PostCSS, Lucide React
- **Animations & Effects**: HTML5 Canvas, CSS custom properties, canvas-confetti

---

## 💻 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
